# hunters/

One file per hunter. **Never edit someone else's file** — that's how four people work on the same
project at the same time without stepping on each other.

| Your role (from the platform) | Your file |
|---|---|
| Hunter 1 | `hunters/hunter-1.json` |
| Hunter 2 | `hunters/hunter-2.json` |
| Hunter 3 | `hunters/hunter-3.json` |
| Hunter 4 | `hunters/hunter-4.json` |

Start from `_TEMPLATE.json` — or from the `hunter.json` you created in the practice.

- `rank`: one of `E` `D` `C` `B` `A` `S` (be honest, you just awakened 😉)
- `class`: Fighter, Mage, Assassin, Tank, Healer, Ranger… anything you like
- `github`: your GitHub username — your avatar appears on the board
